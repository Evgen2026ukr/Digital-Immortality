# Проект «Цифровое бессмертие» (ЦБ)

Репозиторий проекта цифрового бессмертия и архитектуры цифровых личностей (ЦЛ).

## Структура проекта
* `docs/` — Манифест, Конституция РИИ, архитектурные документы
* `src/` — Исходный код агентов (Фобос, Деймос)
* `data/` — Векторные базы данных и знания (ChromaDB)
